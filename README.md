AgriTrace MVP v2
================
This expanded package includes:
- Upgradeable AgriEscrow contract (UUPS) with EIP-712 verification support
- TimelockController deployment example for admin governance
- Chainlink oracle integration example (placeholder / adapter example)
- CLI scripts for create/fund/verify flows
- Expanded React frontend with Create/Fund/Verify UI
- Comprehensive unit tests (Hardhat/Mocha/Chai)

All files are in the `hardhat/` and `frontend/` directories.
